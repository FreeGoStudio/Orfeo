# Orfeo on GitHub: downloads and traffic

Updated **2026-10-21** (daily, automatically) · [Squarebow/Orfeo](https://github.com/Squarebow/Orfeo) · ★ 7 stars · 3 forks · 1 watching

> Orfeo is a free, open-source (GPL-3.0) Windows app for learning piano with MIDI files. It is distributed only through GitHub Releases, as an installer and a portable version. Download totals come straight from GitHub's release statistics and cover every release since the first one; traffic is recorded daily from GitHub's traffic API and kept permanently, because GitHub itself keeps only 14 days.
